# Peta_Interaktif_Ekowisata_Bahari_di_Bangka_Belitung
Peta interaktif yang menyajikan sebaran daya tarik wisata di Bangka Belitung berdasarkan kategori wisata. Dilengkapi informasi, pencarian, filter, dan navigasi, sebagai media informasi dan pendukung penelitian pengembangan ekowisata bahari.

# 🎯 Tujuan
Menyediakan media visual interaktif untuk membantu pengguna memahami persebaran destinasi wisata serta mendukung penelitian pariwisata.

# 🧭 Fitur
- Peta interaktif berbasis Leaflet
- Filter kategori wisata
- Pencarian lokasi
- Popup informasi lengkap
- Navigasi ke Google Maps
